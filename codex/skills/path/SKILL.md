---
name: path
description: Record the expected path of a Usercase research's tasks. Run with the command the dashboard's task screen shows.
---

Call the `instructions` tool of the `usercase` MCP server with `command` set to `path`, `research` set to the first word of the user's message, and `task` set to the second word if there is one. Then follow the instructions it returns, as the user's request.
