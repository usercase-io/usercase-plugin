---
name: install
description: Install the Usercase script on this site from its repository, so survey cards can appear. Use when the user asks to add or install Usercase on their site.
---

Call the `instructions` tool of the `usercase` MCP server with `command` set to `install`, and `url` set to the site address if the user's message has one. Then follow the instructions it returns, as the user's request.
